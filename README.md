# Paradise Nursery - E-Plant Shopping Application

## Project Description
This is the final project for the React course. e-plantShopping is an online plant shopping cart application that offers a variety of house plants. The Paradise Nursery shopping cart features include a landing page, product listing with multiple plant categories, and a shopping cart.

## Repository Name
**e-plantShopping**

## Features Implemented
1.  **Landing Page:** A landing page with a background image, company description, and a "Get Started" button linking to the product listing page.
2.  **Navigation Bar:** A navigation bar with links to the landing page (Paradise Nursery), product listing (Plants), and shopping cart page with a cart icon displaying total quantity.
3.  **Product Listing Page:**
    -   Displays plants in a minimum of two sections (Implemented 5 sections: Air Purifying Plants, Aromatic Fragrant Plants, Insect Repellent Plants, Medicinal Plants, Low Maintenance Plants).
    -   Each plant has a card showcasing image, name, description, cost, and an "Add to Cart" button.
    -   Add to Cart button becomes disabled after adding.
4.  **Shopping Cart Page (CartItem.jsx):**
    -   Displays products in the cart with a card for each type of plant.
    -   Each card has a thumbnail, unit cost, cost for all quantity, buttons to increase/decrease quantity, and a Delete button.
    -   Displays total number of plants and total cost.
    -   Continue Shopping and Checkout buttons.
5.  **State Management:** Implemented using Redux Toolkit (CartSlice.jsx and store.js).

## Technologies Used
- React.js
- Redux Toolkit & React-Redux
- React Router (for navigation logic)
- Vite
- CSS3

## How to Run Locally
1. Clone the repository: `git clone https://github.com/Nafeesa-Kanwal/e-plantShopping.git`
2. Install dependencies: `npm install`
3. Run the app: `npm run dev`
